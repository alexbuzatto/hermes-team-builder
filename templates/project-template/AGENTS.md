# REGRAS DO PROJETO PARA OS AGENTES (AGENTS.md)

1. Mantenha os contratos de API estritamente compatíveis.
2. Todo endpoint deve ter testes de integração implementados por ADA e validados por SHERLOCK.
3. Não adicione dependências pesadas sem aprovação arquitetural de ATLAS.
4. Nenhuma chave secreta ou credencial real deve ser persistida neste repositório.
5. Antes de declarar uma tarefa concluída, execute os testes e comprove com a saída do terminal.
